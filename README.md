# metadata-anonymizer

Чтение служебных метаданных из файлов JPG, PNG и PDF для сервиса анонимизации.
Модуль отдаёт найденные поля в едином виде для всех форматов, чтобы серверная часть
и интерфейс работали с одним контрактом.

## Установка

```
python3.11 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

## Использование

```python
from app import read, clean, detect_format

result = read("/path/to/photo.jpg")
plan = clean("/path/to/photo.jpg")
```

Формат определяется по сигнатуре файла, расширение не используется: PDF,
переименованный в `.jpg`, будет обработан как PDF. Отдельный модуль под формат
выбирать не нужно.

`read()` только читает. `clean()` пока возвращает план очистки: найденные поля
переходят в статус `removed`, файл на диске не меняется. Запись результата
появится на следующем этапе.

CLI для проверки на файле:

```
.venv/bin/python -m app photo.jpg --pretty
.venv/bin/python -m app photo.jpg --clean --pretty
```

## Формат ответа

```json
{
  "file": {"name": "photo.jpg", "format": "jpeg", "size_bytes": 154949},
  "fields": [
    {"key": "author", "label": "Автор", "status": "found", "value": "Иванов Иван Иванович"},
    {"key": "gps", "label": "Геометка", "status": "not_found", "value": null}
  ],
  "warnings": []
}
```

В `fields` всегда присутствуют все поля формата в фиксированном порядке.
Если поля в файле нет, оно возвращается со статусом `not_found`, а не исчезает
из ответа. `value` заполняется только при `found`.

Статусы: `found`, `not_found`, `removed`, `not_supported`, `error`.

Битый, пустой или неподдерживаемый файл не приводит к исключению: все поля
получают `error`, причина пишется в `warnings`. Сервер отвечает клиенту обычным
ответом и показывает, что файл прочитать не удалось.

## Поля

JPG и PNG (11): автор, программа создания, координаты геометки, дата съёмки,
дата изменения, производитель устройства, модель устройства, серийный номер,
правообладатель, описание, история изменений XMP.

PDF (9): автор, программа-создатель, производитель, дата создания, дата
изменения, заголовок, тема, ключевые слова, инструмент XMP.

Если одно и то же значение есть в EXIF и в XMP и они расходятся, в значении
остаётся первое, а второе уходит в `warnings` с пометкой источника. Для
координат показываются оба варианта, потому что по одной паре нельзя понять,
где снимок сделан на самом деле.

Наличие вложений в PDF — не поле для очистки, а признак: файл получает
предупреждение `pdf_has_embedded_files_not_cleaned` и список вложений.
Вложения ищутся в `/Names/EmbeddedFiles`, в `/AF` у корня документа и в `/AF`
у страниц, дубликаты схлопываются по объекту.

## Ограничения текущего этапа

- Очистка файлов не выполняется, `clean()` только планирует её.
- PDF с паролем не читается: возвращается ошибка с пометкой о шифровании.
- Не поддерживаются HEIC и TIFF.
- Приём файлов, проверка лимита 20 МБ, DOCX и удаление временных файлов
  находятся на серверной стороне и в этот модуль не входят.
